# 🚀 INÍCIO RÁPIDO - Relatórios de Oportunidades

## ⏱️ 5 Minutos para Começar

### Passo 1: Abrir a Página
```
http://localhost:3000/relatorios
```

Ou clique em **"Relatórios"** no menu lateral.

### Passo 2: Explorar os Dados
- Veja o **Dashboard** com 8 métricas
- Observe os **Gráficos** de análise
- Explore a **Tabela** com 10 oportunidades

### Passo 3: Usar Filtros
1. Digite um **Nome** no campo de busca
2. Selecione um **Tipo de Serviço**
3. Escolha um **Status**
4. Defina um **Período**

### Passo 4: Visualizar Detalhes
Clique no ícone 👁️ em qualquer linha para ver detalhes completos.

### Passo 5: Exportar Relatório
Clique em **"Exportar"** e escolha:
- 📄 **PDF** - Profissional
- 📊 **CSV** - Para Excel
- 📋 **JSON** - Para integração

## 🎯 Casos de Uso Comuns

### Caso 1: "Quero ver oportunidades abertas de Implante"
1. Filtro "Tipo" → **Implante**
2. Filtro "Status" → **Aberta**
3. Pronto! ✅

### Caso 2: "Preciso de um relatório em PDF"
1. Aplique os filtros que quiser
2. Clique **"Exportar"** → **"PDF"**
3. Arquivo baixa automaticamente ✅

### Caso 3: "Qual é a taxa de conversão?"
Veja o **Card "Taxa de Conversão"** no topo
- Atual: **30%** (3 de 10 oportunidades)

### Caso 4: "Quanto posso faturar?"
Veja o **Card "Valor Potencial"**
- Atual: **R$ 16.720** (com probabilidade)

### Caso 5: "Quero criar uma nova oportunidade"
1. Clique **"+ Nova Oportunidade"**
2. Preencha: Paciente, Email, Valor (obrigatório)
3. Adicione mais detalhes se quiser
4. Clique **"Adicionar"** ✅

## 📊 Entender as Métricas

### Valor Total
Soma de todas as oportunidades (sem probabilidade)
```
Ana (R$3.500) + Carlos (R$800) + ... = R$20.850
```

### Valor Potencial
Valor × Probabilidade (o quanto você deve esperar receber)
```
Ana (R$3.500 × 75%) + Carlos (R$800 × 90%) + ... = R$16.720
```

### Taxa de Conversão
Quantas oportunidades você fecha
```
(3 Fechadas / 10 Total) × 100 = 30%
```

### Valor Médio
Quanto você recebe em média por oportunidade
```
R$20.850 / 10 = R$2.085
```

## 🔍 Filtros Explicados

| Filtro | Funciona | Exemplo |
|--------|----------|---------|
| **Busca** | Por qualquer texto | "Ana", "Implante", "silva@" |
| **Tipo** | Categoria de serviço | Implante, Clareamento, Tratamento |
| **Status** | Situação da oportunidade | Aberta, Em Andamento, Fechada |
| **Data** | Período de registro | De 01/01 a 31/01 |
| **Valor** | Intervalo de preço | De R$500 a R$5.000 |

Todos podem ser **combinados**! Exemplo:
- Tipo = Implante AND Status = Aberta AND Data > 01/01
